## 📦 Déploiement

1. Créer la base de données MySQL sur o2switch
2. Configurer les clés Stripe dans `backend-config.php`
3. Uploader les photos dans `assets/products/`
4. Pointer le domaine `atelierpizza.mon-agenceweb.fr` vers le dossier instance
