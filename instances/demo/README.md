# 🆕 Instance Demo - Template

Ceci est un template d'instance vide. Utilisez ce dossier comme base pour créer une nouvelle instance de restaurant.

## 📋 Comment créer une nouvelle instance

### 1. Copier le dossier demo
```bash
cp -r instances/demo instances/mon-restaurant
```

### 2. Configurer le frontend
Éditer `instances/mon-restaurant/config.template.js` :
- Nom du restaurant
- Couleurs, logo
- Adresse, téléphone
- Horaires d'ouverture
- Réseaux sociaux

### 3. Configurer le backend
Éditer `instances/mon-restaurant/backend-config.template.php` :
- Host MySQL
- Nom de la base de données
- Identifiants

### 4. Ajouter le menu
Via l'admin panel :
- Créer les catégories
- Ajouter les produits
- Configurer les options

### 5. Assets
Placer dans `instances/mon-restaurant/assets/` :
- `logo.png` - Logo du restaurant
- Autres images spécifiques

## ⚠️ IMPORTANT

- ❌ Ne JAMAIS copier une instance existante (Marvelous, etc.)
- ✅ TOUJOURS partir de `instances/demo/`
- ✅ Configurer via l'admin, pas en modifiant le code
