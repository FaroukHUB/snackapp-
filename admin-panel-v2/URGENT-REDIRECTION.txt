  ⚠️ URGENT: PROBLÈME INDEX-MOBILE.PHP SUR LE SERVEUR
═══════════════════════════════════════════════════════

PROBLÈME:
Le navigateur charge toujours index-mobile.php au lieu de index.php

CAUSES POSSIBLES:
1. Anciens fichiers encore sur le serveur
2. Cache du navigateur
3. Fichier .htaccess manquant

═══════════════════════════════════════════════════════
                  🔧 SOLUTION RAPIDE
═══════════════════════════════════════════════════════

ÉTAPE 1: SUPPRIMER LES ANCIENS FICHIERS DU SERVEUR
-----------------------------------------------------
Via FTP ou File Manager, supprimer ces fichiers:
❌ admin-panel-v2/index-mobile.php
❌ admin-panel-v2/index-zero.php
❌ admin-panel-v2/index-medium.php
❌ admin-panel-v2/index-lite.php
❌ admin-panel-v2/index-minimal.php

ÉTAPE 2: UPLOADER LE NOUVEAU .HTACCESS
--------------------------------------
Uploader le fichier:
✅ admin-panel-v2/.htaccess

Ce fichier:
- Force l'utilisation de index.php
- Bloque l'accès aux anciens fichiers
- Désactive le cache navigateur

ÉTAPE 3: VIDER LE CACHE NAVIGATEUR
----------------------------------
Chrome/Edge: Ctrl + Shift + R (ou Cmd + Shift + R sur Mac)
Firefox: Ctrl + F5
Safari: Cmd + Option + R

Ou utiliser le mode Incognito/Navigation privée

ÉTAPE 4: VÉRIFIER
-----------------
Aller sur: http://votre-domaine.com/admin-panel-v2/

Tu devrais maintenant voir index.php avec:
✅ Boutons "Ajouter Produit" et "Nouvelle Catégorie"
✅ SELECT statut avec 3 options (Disponible/Non dispo/Rupture)
✅ Toutes les corrections récentes

═══════════════════════════════════════════════════════
               SI ÇA NE FONCTIONNE TOUJOURS PAS
═══════════════════════════════════════════════════════

1. Vérifier que index.php est bien sur le serveur:
   → admin-panel-v2/index.php doit exister (18 KB)

2. Vérifier les permissions:
   → chmod 644 admin-panel-v2/index.php
   → chmod 644 admin-panel-v2/.htaccess

3. Si tu as un cache serveur (Cloudflare, etc):
   → Vider le cache CDN/proxy

4. En dernier recours:
   → Renommer index.php en main.php
   → Aller sur: /admin-panel-v2/main.php
